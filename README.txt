Custom Cursor for Roblox
========================

This pack contains two cursor images for the Roblox client:
  ArrowFarCursor.png  - the main pointer
  ArrowCursor.png     - the near/hover pointer

HOW TO INSTALL (manual)
  1. Close Roblox.
  2. Open the Roblox cursors folder:
     - Right-click the Roblox Player shortcut -> Open file location
       (or find RobloxPlayerBeta.exe). That is your version folder:
       ...\Versions\<version>\
     - Go into:  content \ textures \ Cursors \ KeyboardMouse \
  3. KEEP A BACKUP so you can undo it later: rename the originals
       ArrowCursor.png     -> ArrowCursor_old.png
       ArrowFarCursor.png  -> ArrowFarCursor_old.png
     (do NOT just delete them - the _old files are how you restore).
  4. Copy ArrowCursor.png and ArrowFarCursor.png from this pack
     into that folder.
  5. Start Roblox. Done.

HOW TO RESTORE THE ORIGINAL CURSOR
  1. Close Roblox.
  2. In the same folder, delete our ArrowCursor.png / ArrowFarCursor.png.
  3. Restore the default:
     - rename your backup:  ArrowCursor_old.png -> ArrowCursor.png
                            ArrowFarCursor_old.png -> ArrowFarCursor.png
     - no backup? we keep the original Roblox cursors + restore steps here:
       https://custom-cursor.com/how-to-use/roblox/how-to-restore-the-original-roblox-cursor
  4. Start Roblox.

Note: a Roblox update installs a new version folder and resets the cursor.
Repeat the steps, or use Bloxstrap (Mods folder) to re-apply automatically.

Full step-by-step guide: https://custom-cursor.com/how-to-use/roblox
More cursors: https://custom-cursor.com/
